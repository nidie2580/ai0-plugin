对话设置

全局AI：开启后，仅在「全局AI群号」列表内的群里，所有非命令消息都会触发回复（无需 @机器人）；「忽略前缀」中的消息不触发。与 QQ 命令 #ai全局ai on/off 等效，保存后立即生效。多模型并行回答：一条用户消息同时交给所有已配置模型各自作答。开启「模型间互聊」后，各模型会看到彼此的发言（带 [*] 标记），可就同一话题相互点评/聊天。「艾特指定模型」允许用 /模型名 把消息单独转给某个模型。「群操一致性确认」：互聊开启时，AI 回复里带出的群操作会先转发给其他模型确认，任一否决则取消。「多模型协同讨论」：≥2 个模型先互相商量（各自输出立场→可同意他人版本→本地判定收敛），达成过半共识即输出一份统一回复；达最大轮数未收敛则由裁判模型综合。开启后群聊只发最终一条结论，不再逐个刷屏。注意：并行回答会成倍增加模型 API 调用次数。

防 AI 互聊循环

群里同时存在多个机器人时，它们可能互相 @ 形成无限互答烧 token。此机制在「同群同账号短窗口内连续回复达上限」时判定为疑似循环，进入冷却静默。正常人类间歇聊天几乎不会误判。关闭总开关即停用该保护。

私聊速率限制

同一用户在窗口内私聊触发超过上限则静默跳过，避免刷 API。群聊不受此项限制。

点歌设置

开启后，AI 对话内识别到点歌/推荐歌意图即自动搜索并发送音乐卡片；拿不到可播直链时自动降级为文本链接。点歌使用网易云/QQ音乐公开接口+歌曲页元数据爬虫，不依赖任何个人登录 Cookie，无需额外配置。

Agent 配置

Agent 单次任务最大 LLM 调用轮数（≥1，无上限截断，受 API 配额/超时自然约束）。低配额 API（如 RPM≤3）建议 2~3；高配额可 5~8。任务硬超时默认 600000ms（10 分钟），范围 30000~1800000ms。

系统提示词

支持动态变量（发送给模型时替换）：<master> 主人QQ、<user> 当前发送者、<bot> 机器自身、<admin> 管理员列表。
