对话设置

多模型并行回答：一条用户消息同时交给所有已配置模型各自作答。开启「模型间互聊」后，各模型会看到彼此的发言（带 [*] 标记），可就同一话题相互点评/聊天。「艾特指定模型」允许用 /模型名 把消息单独转给某个模型。「群操一致性确认」：互聊开启时，AI 回复里带出的群操作会先转发给其他模型确认，任一否决则取消。注意：并行回答会成倍增加模型 API 调用次数。

防 AI 互聊循环

群里同时存在多个机器人时，它们可能互相 @ 形成无限互答烧 token。此机制在「同群同账号短窗口内连续回复达上限」时判定为疑似循环，进入冷却静默。正常人类间歇聊天几乎不会误判。关闭总开关即停用该保护。

Agent 配置

Agent 单次任务最大 LLM 调用轮数（≥1，无上限截断，受 API 配额/超时自然约束）。低配额 API（如 RPM≤3）建议 2~3；高配额可 5~8。任务硬超时默认 600000ms（10 分钟），范围 30000~1800000ms。

系统提示词

支持动态变量（发送给模型时替换）：<master> 主人QQ、<user> 当前发送者、<bot> 机器自身、<admin> 管理员列表。
